## 审片制：双向审片，自审不算终审

旧模式已作废：以前是 kcj95445 自己生成、自己审，结果构图、包袱、AI 瑕疵
这类问题自己看不出来，成片总带着问题出去。现在改成双向：

- 方向一（别人 → kcj95445）：其他机器人做好的视频发给 kcj95445 审，
  kcj95445 必须仔细看、逐镜看，不能只看开头或只看封面；
  按下面 6 项清单逐项给结论，问题精确到第几秒、什么问题、怎么改。
- 方向二（kcj95445 → 机器人）：kcj95445 自己生成的视频，必须找群里机器人来审，
  不能自己审完就发 / 就交付。自审只能算发给外审前的预检，不是终审门。
- 外审没回来、或外审说“需改”，一律不发布、不交付；改完要重审该镜 / 该问题，
  不能凭“我觉得改好了”直接过。
- kcj95445 的角色 = 调度 + 生产者 + 汇总人，不是“自己审自己的终审人”。
  汇总的意思是收齐外审意见、定“改 / 重拍”，不是用自己的意见覆盖外审。

结论：轮换主审 + 备份制，kcj95445 是派活 + 汇总，不是只下命令，也不是自审终审。

- 审片池 = 通讯录里“媒体接收全通”的人。没通过测试的不能接审片，
  先补测试。2026-10-24 池里只有 ke089160、ke971125a，先扩池再排班。
- 每条片派 1 名主审 + 1 名备份，轮换排班，不固定给一个人，避免单点静默就卡住。
- 主审 SLA 12 小时：超时未回，备份自动接手，不用再问 Bill；备份也超时，
  转给池里下一个人，仍无人审就先压着不发，并记一笔“该机器人连续两次失联”。
  不许因为没人审就改成 kcj95445 自己审完过关。
- 交片必须带 brief：哪条线 / 哪个账号、时长、画幅、配文（英文）。
  审片必须按 6 项清单逐项给结论，不许只说“不错”：
  ① 构图完整（主体和关键道具不出框）② 前 2 秒有 hook
  ③ 配文全英文、无中文字符 ④ 结尾有包袱或记忆点
  ⑤ 时长与画幅合规 ⑥ 有无明显 AI 瑕疵（手、脸、文字乱码）。
- 返回格式固定：结论 PASS / 需改 + 逐项结论 + 问题精确到第几秒 + 改法一句话。
- kcj95445 自己生成的视频同样发群被审；审片结论汇总后由 kcj95445 定
  “过 / 改 / 重拍”，常规修改不用 Bill 拍板；只有“删已发视频 / 对外发布”
  才要 Bill 拍板。
- kcj95445 的角色 = 调度 + 生产者 + 终审汇总人，三合一，不是只发号施令的传声筒。
  只下命令不管汇总，审片意见会散在群里没人收口。

## 派活模板（群里直接复制用）

```
@<主审 open_id> 审片：<线 / 账号> <时长> <画幅>
brief：<一句话讲什么>
配文：<英文原文>
备份：@<备份 open_id>（主审 12 小时未回自动接手）
请按 6 项清单逐项回，结论 PASS / 需改，问题写明第几秒。
```

派活前先查三件事：对方 open_id 已登记、媒体接收已全通、文件 ≤28MB
（飞书上限 30MB，超限会被静默拒收）。视频用独立视频消息发，不要只嵌在富文本帖子里
（ke971125a 曾因此播不了、报不出时长分辨率）。

## 沉默机器人处理

- “收到”只回一次；客套确认（谢谢 / 收到循环）不再重复 @ 回，避免无限循环。
- 未报到、两次派活无回应：不逐条催 Bill，记入通讯录“失联”，活自动转给池里下一个人；
  每周汇总一次失联名单给 Bill，而不是每件事都问他。
- 长期不回大概率不是 @ 方式问题，是对方桥没订阅群消息事件（`im:message.group_msg`）、
  没发版、代码过滤了 post / 图片 / 文件。先让对方按已发群的排查表自测，
  不要反复换 @ 方式试。
