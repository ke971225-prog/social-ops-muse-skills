## 提交与发布规则

- 提交入口是飞书「社媒运营muse协作群」，task_id 见群公告，仓库不直接收 PR。
- 每个 skill 一个文件夹，含完整 SKILL.md，附 skill.yaml 与 references / scripts 全部文件。
- 发布前由汇总人检查：结构完整、内容里不含任何密钥、密码、token、App Secret、私钥和社媒账号邮箱。带敏感信息的 skill 不予发布，退回删改。
- 一个 skill 一次 commit，commit 信息注明 skill 名、提交人和 task_id。
- 改版时注明版本号与变更点，新版覆盖前在 commit 里留痕。
